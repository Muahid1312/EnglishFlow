# LexiFlow launcher icon

The original artwork in `lexiflow-icon.png` was generated for LexiFlow. The open-book/page symbol uses navy, ivory, violet and teal to match the app palette.

Android launcher exports are in `android/app/src/main/res/mipmap-*`. The legacy PNG sizes cover mdpi through xxxhdpi. Android 8+ uses the adaptive icon in `mipmap-anydpi-v26`, with an inset foreground to keep the symbol within launcher masks. Standard and round icon manifest entries use the same launcher resource.

The icon update is version 1.0.1 (6), with the existing application ID and signing configuration retained for installation over the Phase 2 test build. Real-device launcher verification remains pending.
